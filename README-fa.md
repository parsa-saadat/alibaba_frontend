# فرانت‌اند — نسخهٔ ۷

## اجرا
Node.js 20.19+ یا 22.12+ پیشنهاد می‌شود.
```sh
npm ci
npm run dev
```
API پیش‌فرض `/api` است؛ Vite آن را به بک‌اند پورت 3000 پروکسی می‌کند. در production باید reverse proxy معادل تنظیم شود.
```sh
npm run build
```

## اصلاحات این نسخه
- انتخابگر زبان و ارز صفحه‌های ورود/ثبت‌نام/کد تأیید داخل همان کارت لوگو و فرم قرار دارد؛ نوار بیرونی حذف شده است.
- placeholder نام، معرفی کوتاه، توضیحات، ادیتور Markdown و تگ‌ها بر اساس زبان **محتوای در حال ویرایش** عوض می‌شود، نه زبان رابط. انتخاب English/فارسی/العربية/Türkçe، هم جهت و هم راهنمای فیلد را تغییر می‌دهد.
- مسیرهای جدید در ساختار components / hooks / i18n / styles مرتب شده‌اند. ادیتور ترجمهٔ قدیمی و اسکریپت‌های موقت استخراج/ترجمه حذف شده‌اند. کدهای اضافه‌شده با قالب دو فاصله‌ای، نام‌های خواناتر و جداسازی منطق از نما مرتب شده‌اند.
- تنظیمات زبان و ارز سایت در منوی موبایل و فوتر دسکتاپ، و در پنل‌ها داخل منو و نوار موبایل است. عنوان محصول چسبان نیست و انتخابگر زبان Markdown تکرار نمی‌شود.

## ترجمهٔ خودکار و ارز
برای استفاده از این نسخه بک‌اند نسخهٔ ۷ را هم نصب کنید. دکمهٔ تکمیل ترجمه، زبان انتخابی را مبنا می‌گیرد و فقط فیلدهای خالی زبان‌های دیگر را پر می‌کند؛ ذخیرهٔ خودکار انجام نمی‌شود. متن با کلیک شما به سرویس خارجی Google فرستاده می‌شود؛ بازبینی تخصصی لازم است. کد و نشانی لینک‌های Markdown حفظ می‌شوند. در خطای شبکه یا تغییر متن مبنا، نتیجهٔ نامعتبر اعمال نمی‌شود.

ارز ورود پیش‌فرض: en=USD، fa=IRT (تومان)، tr=TRY و ar=AED. قیمت کاتالوگ سمت سرور فقط USD ذخیره می‌شود؛ نمایش بر اساس نرخ معتبر API است. فیلدهای اصلی سازگاری در اسناد، خودکار از ترجمه ساخته می‌شوند و نیاز به ورود تکراری ندارند. سفارش و پرداخت قبلی دوباره ارزش‌گذاری نمی‌شود.
